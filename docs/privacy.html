Kebijakan Privasi Adaptify

Terakhir diperbarui: 22 Juli 2026

Adaptify ("Aplikasi") adalah aplikasi pendamping (companion app) untuk smartwatch Xiaomi Watch 2 yang merekomendasikan genre musik berdasarkan data aktivitas dan detak jantung pengguna secara real-time. Kebijakan Privasi ini menjelaskan data apa saja yang dibaca oleh Aplikasi, bagaimana data tersebut diproses dan disimpan, serta hak pengguna terhadap data tersebut.

1. Data yang Dibaca

Aplikasi (melalui smartwatch pendamping) membaca sensor berikut dari perangkat wearable:

  • Detak jantung (Heart Rate / HR) — dibaca melalui sensor sensor detak jantung pada smartwatch.
  • Jumlah langkah (Step Count) — dibaca melalui sensor pedometer pada smartwatch.

Data tambahan seperti variabilitas detak jantung (HRV/RMSSD), data akselerometer, dan giroskop juga dibaca oleh smartwatch untuk keperluan klasifikasi mode aktivitas (misalnya Relax, Low Activity, atau High Activity), namun hanya nilai turunan (indeks/skor/mode) yang dikirim ke aplikasi HP — bukan data mentah sensor gerak.

2. Bagaimana Data Diproses

Seluruh pemrosesan data dilakukan secara lokal (on-device):

  • Perhitungan indeks aktivitas/HRV dilakukan langsung di smartwatch.
  • Klasifikasi mode aktivitas dan rekomendasi genre musik dilakukan langsung di aplikasi HP.
  • Tidak ada pemrosesan data yang dilakukan di server eksternal, karena Aplikasi ini tidak memiliki backend/server.

3. Bagaimana Data Disimpan

Data yang dibaca disimpan secara lokal di perangkat HP pengguna, menggunakan:

Media PenyimpananJenis Data
Room Database (lokal, di dalam perangkat)Riwayat/log heart rate, step count, mode aktivitas, dan riwayat rekomendasi genre musik.
SharedPreferences (lokal, di dalam perangkat)Preferensi pengguna, konfigurasi aplikasi, dan pengaturan pemetaan genre musik.

Data ini tidak pernah disimpan di luar perangkat pengguna — tidak ada database cloud, tidak ada penyimpanan pihak ketiga, dan tidak ada backup otomatis ke server manapun.

4. Transmisi Data

Data hanya berpindah dari smartwatch ke HP melalui koneksi Bluetooth lokal (menggunakan Wearable Data Layer API dari Google Play Services), yang berjalan sepenuhnya di antara kedua perangkat milik pengguna dan tidak melalui internet atau server eksternal.

Aplikasi tidak mengirim data pengguna ke server, layanan cloud, atau pihak ketiga mana pun, termasuk tidak ada analitik pihak ketiga, iklan, atau layanan pelacakan (tracking) yang mengumpulkan data kesehatan pengguna.

5. Berbagi Data dengan Pihak Ketiga

Adaptify tidak membagikan, menjual, atau mentransfer data pengguna kepada pihak ketiga mana pun.

6. Hak Pengguna dan Penghapusan Data

Karena seluruh data disimpan secara lokal di perangkat pengguna, pengguna memiliki kendali penuh atas data tersebut:

  • Pengguna dapat menghapus seluruh data aplikasi kapan saja melalui pengaturan sistem (Settings > Apps > Adaptify > Clear Data).
  • Meng-uninstall Aplikasi dari HP dan/atau smartwatch akan menghapus seluruh data secara permanen, karena tidak ada salinan data yang tersimpan di luar perangkat.

7. Data Anak-Anak

Aplikasi ini tidak ditujukan untuk anak-anak di bawah usia 13 tahun dan tidak secara sengaja mengumpulkan data dari anak-anak.

8. Perubahan Kebijakan Privasi

Kebijakan Privasi ini dapat diperbarui dari waktu ke waktu. Perubahan akan dipublikasikan pada halaman ini dengan tanggal pembaruan yang baru.
